How to use these guides

Make free resources work harder.

Reading about English helps, but using it is what changes your level. Try this simple routine with any guide.

  1. Read once for ideas

    Don't stop for every new word. Get the main message first.

  2. Choose one thing to try

    Pick a single tip or phrase you can use today.

  3. Use it out loud

    Say it, write it or record it. Practice makes it yours.

  4. Come back in a week

    Re-read and notice what now feels easy. That's progress.
